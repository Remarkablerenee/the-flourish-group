# The Flourish Group

Version 1 static website for The Flourish Group.

## Publish with GitHub Pages

1. Create a GitHub repository (for example `the-flourish-group`).
2. Upload all files in this folder to the repository root.
3. In **Settings → Pages**, choose the publishing source for the main branch/root.
4. Set the custom domain to `theflourishgroup.co`.
5. Keep the included `CNAME` file in the repository root.
6. At your domain provider, point the apex domain to GitHub Pages using the current A records listed in GitHub's documentation, and add `www` as a CNAME to your GitHub Pages hostname if you want both versions.
7. Once GitHub provisions the certificate, enable **Enforce HTTPS**.

## Notes

This is intentionally a no-backend Version 1. It is designed to be expanded later with real opportunity links, resources, service inquiries, analytics, forms, and future ventures.
